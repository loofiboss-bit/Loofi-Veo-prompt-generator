# Loofi Creator Studio v21.0.0

v21 makes editing and delivery easier to follow and project saves more reliable.

## Highlights

- Follow four delivery steps: check, review, export video and save files.
- Distinguish finished renders, confirmed file saves and older results.
- Coordinate saves before manual save, project copy, export and production handoff; preserve conflicts and edits made while saving.
- Filter video, audio, images, references and generated media; protect assets used by clips or production profiles.
- Continue the active project from Start with recovery actions for known conflicts, draft errors and missing media.
- Review optional caption suggestions for overlaps, long lines and reading speed without automatic edits.
- Use improved welcome-dialog focus handling, project status and delivery feedback in all six languages.
- Refresh Gemini planning and prompt guidance, with compatible dependency security updates.
- Keep ordinary durable video jobs on supported Veo adapters; conversational edits use the separate Interactions path.
- Use disclosed conservative post-promotion price ceilings for new Flash and Argon models.

## Upgrade notes

Existing projects and archive formats remain supported. Back up important projects before upgrading.
Caption suggestions are optional editorial guidance. Older render jobs keep their saved filename but
are identified as previous results when currentness cannot be established. AI generation remains
optional and requires explicit approval; live provider execution was not part of release validation.

Download the [GitHub release](https://github.com/loofiboss-bit/Loofi-Veo-prompt-generator/releases/tag/v21.0.0)
and verify packages against `SHA256SUMS.txt`. Fedora 44 x86_64 users can also use
[COPR](https://copr.fedorainfracloud.org/coprs/loofitheboss/loofi-creator-studio/).

Automated checks, packaged smoke tests and public publication are verified separately. Physical
microphone, screen-reader and native desktop qualification remain untested for this release.
See the [release runbook](../RELEASE.md) for publication and qualification boundaries.
