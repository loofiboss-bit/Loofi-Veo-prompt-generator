# First Project

Create a small project you can save, revise and export before starting a larger production.

1. Open **Projects**, name and create a project, then open it.
2. In **Prompt Studio**, choose Video or Music & Lyrics and enter a focused idea.
3. Select **Build copy-ready pack** and edit one of the three variants.
4. Inspect **Readiness checks**, then save a version in **Versions and comparison**.
5. Wait for **Saved**. If the status reports **Not saved**, keep the window open and retry.
6. Copy your package for a manual destination, or choose Veo API to prepare an internal production plan.
7. Export the project from **Projects** as a `.loofi-project` archive.

For image-based video, add the required local images before building. A template does not transfer
project media or provider handles, so select references again in each receiving project.

For internal production, follow [Production Workflow](Production-Workflow.md): reviewing a local plan
and approving a paid request are separate actions. ComfyUI rendering, Live audio, LAN collaboration
and Foley generation are disabled incomplete integrations.

Continue with [Prompt Quality and Iteration](Prompt-Quality-and-Iteration.md),
[Assets and Continuity](Assets-and-Continuity.md) or [Project Backup and Restore](Project-Backup-and-Restore.md).
