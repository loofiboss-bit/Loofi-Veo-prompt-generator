# M0 technical risks

| Risk                               | Treatment and evidence required                                                                                                                                                                                                                                               |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pre-1.0 bridge and code generation | Pin CXX-Qt 0.10.0, lock crates, build with actual Fedora Qt and test typed QObject behavior.                                                                                                                                                                                  |
| Worker/Qt object lifetime          | Bounded worker, cancellation, generation check, queue failure handling and destruction during work. Filesystem syscalls on a stalled remote mount cannot be cooperatively interrupted; close can wait for them. M0 is qualified for readable local files, not stalled mounts. |
| Explicit Qt model protocol         | Rust-owned list with role and insertion tests plus QAbstractItemModelTester.                                                                                                                                                                                                  |
| Cargo/CMake duplicate builds       | One production orchestrator; Cargo checks use an external target directory. QML metadata must be generated before lint.                                                                                                                                                       |
| KDE native dialog requirements     | QApplication plus theme plugin; validate actual Wayland selection/cancellation, not only dialog visibility.                                                                                                                                                                   |
| GPU/codec differences              | Decode frames and render geometry with real Qt components; record backend, report unsupported environments.                                                                                                                                                                   |
| License/product direction          | GPLv3 selected for native; Electron MIT retained. Reassess commercial product direction before distribution.                                                                                                                                                                  |
| Unequal feature breadth            | Benchmark only named equivalent workloads; M0 results cannot establish full application rewrite benefits.                                                                                                                                                                     |
| Startup observer overhead          | Report Qt-frame vs Electron CDP methods; no hard threshold or cold-cache inference.                                                                                                                                                                                           |
| Session-only projects              | UI says changes disappear on restart; no migration or persistent format promises.                                                                                                                                                                                             |
