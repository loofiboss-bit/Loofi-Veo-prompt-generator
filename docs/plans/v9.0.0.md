## Phase 4 — UI, accessibility, responsive behavior, and localization

### Design direction

Subject: a local-first control room for independent video and music creators. The page job is to
move one project confidently from brief to exported media without exposing implementation modules.

- Palette: Ink `#0B1020`, Slate `#172033`, Paper `#F6F8FC`, Signal Blue `#2563EB`, Success
  `#15803D`, Warning `#B45309`. Blue is the only primary accent; state colors remain semantic.
- Type: retain the packaged system sans stack for offline reliability; use a compact mono utility
  face only for prices, model IDs, and provenance.
- Layout: a quiet six-destination rail plus one numbered workflow spine. The memorable element is
  the **cost ledger** beside Generate: source, assumptions, confidence, and approved ceiling read as
  one auditable strip rather than a decorative card.
- Motion: one step-transition and progress announcement pattern, disabled by reduced-motion.

The deliberately rejected alternative was a gradient-heavy provider dashboard: it competes with
the creative work, weakens state semantics, and repeats the current neon/gradient drift.

```text
+------+-------------------------------------------------------------+
| six  | Create  Project title                         Local / Saved  |
| nav  | Brief — Scenes — Assets — Generate — Review — Export       |
|      |-------------------------------------------------------------|
|      | current step content                     | cost ledger      |
|      |                                          | source / max     |
|      |-------------------------------------------------------------|
|      | Back                         one primary next/action button |
+------+-------------------------------------------------------------+
```
