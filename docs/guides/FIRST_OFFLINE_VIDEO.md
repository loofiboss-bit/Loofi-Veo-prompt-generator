# Export your first offline video

**Result:** a playable MP4 made from included example clips, with no account, provider key, or
watermark. These steps describe v15 development; desktop export requires the verified bundled
rendering runtime. Stable v14.2.1 installers do not include this new workflow.

1. Open **Start**. In the welcome guide, choose your language and creative goal, then select
   **Try an offline example**. You can also skip the guide and use Start directly.
2. In **Try it offline**, choose **Open example** on Quick tip, Short story, or Ambient visual.
   This creates a separate project with local clips, audio, captions and an editable timeline.
3. In **Timeline**, play the example. Adjust the arrangement or trim a clip if you want. To change
   the idea or future generation instructions, open **Prompt Studio**; building a prompt pack
   does not alter the included clips or submit generation.
4. Find **Export video** in Timeline. Choose **9:16**, **16:9**, or **1:1**, then **720p** or **1080p**.
   Leave **Fit entire image** selected for a first export. Use the crop preview before selecting
   **Crop to fill** so you can see which edges will be removed.
5. Edit the publication title and description. Expand **Captions** to check the example text and
   choose **Burn into video** if you want the text visible in every video player.
6. Select **Export video**. Wait for rendering and verification to finish, then select **Save MP4**
   and choose a file with the native save dialog. Play the saved file in your video player.

The examples use original geometric animation and synthesized audio with a CC0 dedication; they
are reusable media, not examples of paid AI generation. A complete project remains on your computer
so you can return to it through **Start → Recent projects** or **Projects**.

If export is unavailable, read the local renderer message. The web preview can edit the project
but cannot run native MP4 export. If a clip is missing or unsupported, use **Locate affected clip**
and repair that clip before retrying. Shorten the timeline when it exceeds 60 seconds. Do not expect
a cancelled render to produce a finished file.

To start on Prompt Studio next time, change **Open the app on** at the bottom of Start.
See [captions and style](CAPTIONS_AND_STYLE.md) for further customization.
