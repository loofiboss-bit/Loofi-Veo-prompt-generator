# Bundled creator fonts

These unmodified Noto fonts support offline caption rendering and previews. Latin,
Swedish, Arabic and Japanese glyphs are included. No font CDN is used.

Source distributions:

- Noto Sans, Noto Serif, Noto Sans Arabic: Fedora packages
  `google-noto-*-vf-fonts-20251201-2.fc44`, upstream Noto font collection.
- Noto Sans CJK variable collection: Fedora package
  `google-noto-sans-cjk-vf-fonts-2.004-11.fc44`.

The accompanying Apache 2.0 and SIL Open Font License notices are retained from
the source distributions. The font files retain their embedded naming and notices.
The CJK collection is intentionally complete; it is not limited to the demo text.
