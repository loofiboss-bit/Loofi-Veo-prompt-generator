# Quick Start

## Make a Flow/Veo prompt

1. Open `/` or `/studio` and select **Video**.
2. Write one subject, one action, and one focused scene in the idea field.
3. Choose the target, prompt mode, aspect ratio, and duration.
4. Add camera, style, environment, references, dialogue, or audio only when useful.
5. Select **Optimize prompt** and copy the recommended result or one of the two alternatives.

## Make a Suno lyrics pack

1. Open `/studio?mode=music` or select **Music & Lyrics**.
2. Choose the lyrics language and vocal/instrumental mode.
3. Describe the theme, mood, hook, story, and production direction.
4. Generate the pack and review Title, Style of Music, section-tagged Lyrics, and notes.
5. Copy the fields into Suno Custom Mode with **Copy Style**, **Copy Lyrics**, or **Copy All**.

Nothing is sent to Flow, Veo, or Suno automatically. **Generate in app** creates a local draft and
opens the approval-gated production path only when you explicitly choose it.
