# Production workflow

Prompt Studio is the first step for copy-ready prompts and lyrics. **Production** is the advanced
media workflow: **Brief** defines intent. **Scenes** confirms shot language. **Assets** validates
references. **Generate** exposes model and maximum cost before submission. **Review** compares A/B
takes with scores and notes. **Export** creates the Creative Pack and portable project bundle.

Local edits support undo. A submitted paid call cannot be undone; retakes and revisions require a new approval.
